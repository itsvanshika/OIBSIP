# Data Science Internship Projects — Oasis Infobyte

Three end-to-end analysis and modelling projects completed during the Oasis Infobyte data science internship (OIBSIP). Each notebook walks through the full workflow: loading and cleaning data, exploratory analysis, visualisation and (where relevant) a predictive model.

| Project | Business question | Approach | Notebook |
|---|---|---|---|
| 📈 **Sales Prediction** | How does advertising spend drive sales? | EDA, feature/target split, Linear Regression, evaluated with R² | [Open](sales%20prediction%20using%20python.ipynb) |
| 📉 **Unemployment Analysis** | How did unemployment change across regions and over time? | Missing-value checks, trend and regional comparisons, interactive Plotly charts | [Open](unemployment_analysis_using_python.ipynb) |
| 🌸 **Iris Flower Classification** | Can species be predicted from flower measurements? | Compared Logistic Regression, KNN, Decision Tree, SVM and Naive Bayes on accuracy | [Open](IrisFlowerClassification.ipynb) |

## Skills demonstrated

- **Data wrangling:** Pandas, NumPy — cleaning, missing-value handling, aggregation
- **Visualisation:** Matplotlib, Seaborn, Plotly Express
- **Modelling:** Scikit-learn — regression, classification, train/test split, model comparison
- **Communication:** each notebook is structured as a short narrative from question to conclusion

## Run it yourself

Every notebook opens directly in Google Colab via the badge at its top, or locally:

```bash
pip install pandas numpy matplotlib seaborn plotly scikit-learn jupyter
jupyter notebook
```
